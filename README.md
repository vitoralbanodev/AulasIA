## 🚀 Como usar este repositório no Google Colab

A forma mais fácil de executar os notebooks é diretamente via Google Colab:

1. Acesse o [Google Colab](https://colab.research.google.com/).
2. Vá em **Arquivo > Abrir notebook**.
3. Selecione a aba **GitHub**.
4. Cole a URL deste repositório e selecione o notebook que deseja estudar.

> **Dica:** Para salvar suas alterações, não esqueça de selecionar `Arquivo > Salvar uma cópia no GitHub` após fazer seus testes.
